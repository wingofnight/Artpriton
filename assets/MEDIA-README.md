# Музыка и видео

Настройка коллекции — `js/media.js`.

## Песни

Создайте папку `assets/music`, положите туда MP3 и обложки.
В массив `MUSIC_TRACKS` добавьте записи:

```js
{title:'Название песни', artist:'Артпритон', src:'assets/music/song.mp3', cover:'assets/music/song-cover.jpg'}
```

Плеер автоматически включит кнопки, выбор кассет и переключение песен.
Поле `cover` можно оставить пустым. Название показывается на кассете.

## Обложки VHS

Создайте папку `assets/video`, добавьте обложки и укажите их пути в поле `cover` массива `VIDEO_TAPES`.
Наклейка VHS имеет пропорции 2:1 — например 1200×600 px.
Наклейка аудиокассеты — около 3:1, например 1200×400 px; важные элементы размещайте в центре, подпись накладывается поверх.

## Фон музыки

Можно подготовить широкий фон 1600×900 с приглушённой аппаратурой справа и свободным пространством слева. Пока фон сделан стилями, без внешних изображений.

Главный клип остаётся в блоке «Артпритон в кадре». Остальные клипы открываются из VHS-кассет. Закрытие окна выгружает VK-плеер.
