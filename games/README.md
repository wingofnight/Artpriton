# Подключение трёх игр

Положите браузерные версии игр в отдельные папки внутри `games/`.
Сохраните структуру веб-экспорта, включая изображения, звук и файлы движка.

В `js/services.js` для каждой записи массива `GAMES` задайте:

- `title` — название игры;
- `url` — путь к стартовой странице, например `games/my-game/index.html`;
- `cover` — путь к обложке картриджа;
- `instructions` — массив строк с правилами и управлением.

Пустой `url` оставляет картридж со статусом «Скоро».
Игры открываются в iframe внутри телевизора. Закрытие окна выгружает игру и звук.
Для веб-экспортов, которым нужен HTTP, используйте локальный сервер вместо `file://`.

При открытии и закрытии справки плеер отправляет сообщения
`artpritone:game:pause` и `artpritone:game:resume`. Игра может обрабатывать
их через `window.addEventListener('message', ...)`, проверяя отправителя.
Без обработчика эти сообщения не останавливают игровой цикл.
